# 深色模式切换测试指南

## 测试目的
验证文字修仙游戏的深色模式切换功能，确保所有 Element Plus 组件在两种模式下正常显示。

---

## 一、切换入口

### 1.1 主要入口
- **位置**：游戏设置对话框
- **触发**：主页面 → 设置按钮 → 显示设置
- **组件**：el-switch（开关）

### 1.2 切换代码
```javascript
// homePage.vue:2632-2641
const handleDarkModeChange = (val) => {
  const gameContainer = document.querySelector('.game-container')
  if (gameContainer) {
    gameContainer.classList.toggle('dark', val)
  }
  gameNotifys({
    title: '显示模式',
    message: val ? '已切换到暗色模式' : '已切换到浅色模式'
  })
}
```
