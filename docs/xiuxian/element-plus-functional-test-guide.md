## 二、功能测试用例

### 2.1 el-drawer 功能测试

#### 测试用例 1：抽屉打开/关闭
**步骤**：
1. 点击"修仙境界表"按钮
2. 观察抽屉从右侧滑入
3. 点击关闭按钮
4. 观察抽屉滑出

**预期结果**：
- 抽屉滑入动画流畅（约 300ms）
- 关闭按钮响应灵敏
- 抽屉滑出动画流畅
- 无卡顿或闪烁

#### 测试用例 2：抽屉方向
**步骤**：
1. 打开"修仙境界表"（direction="ltr"，从左滑入）
2. 打开"炼器"（direction="rtl"，从右滑入）

**预期结果**：
- ltr 抽屉从左侧滑入
- rtl 抽屉从右侧滑入
- 滑入方向与配置一致

#### 测试用例 3：抽屉头部样式
**步骤**：
1. 打开任意抽屉
2. 检查头部木纹渐变背景
3. 检查标题字体和颜色

**预期结果**：
- 头部显示木纹渐变（#8B4513 → #A0522D）
- 标题为金色（#b8860b）
- 字体为行楷（STXingkai）

#### 测试用例 4：抽屉内容区
**步骤**：
1. 打开"图鉴与成就"抽屉
2. 滚动内容区
3. 检查滚动条样式

**预期结果**：
- 内容区背景为宣纸色（#f7f4ed）
- 滚动条样式一致
- 内容可正常浏览

### 2.2 el-dialog 功能测试

#### 测试用例 1：对话框打开/关闭
**步骤**：
1. 点击"设置"按钮
2. 观察对话框淡入效果
3. 点击关闭按钮
4. 观察对话框淡出效果

**预期结果**：
- 对话框淡入动画流畅
- 关闭按钮响应灵敏
- 对话框淡出动画流畅
- 水墨淡入效果明显

#### 测试用例 2：对话框遮罩层
**步骤**：
1. 打开任意对话框
2. 点击遮罩层（对话框外区域）
3. 验证对话框是否关闭

**预期结果**：
- 遮罩层显示（半透明黑色）
- 点击遮罩层关闭对话框
- 关闭动画流畅

#### 测试用例 3：对话框头部
**步骤**：
1. 打开设置对话框
2. 检查头部木纹匾额样式
3. 检查标题显示

**预期结果**：
- 头部显示木纹渐变
- 标题为金色带文字阴影
- 字体为行楷

#### 测试用例 4：对话框表单功能
**步骤**：
1. 打开设置对话框
2. 切换深色模式开关
3. 验证开关状态变化
4. 验证模式切换生效

**预期结果**：
- 开关状态实时更新
- 模式切换通知显示
- 样式立即变化

### 2.3 el-tag 功能测试

#### 测试用例 1：标签显示
**步骤**：
1. 查看页面中的标签组件
2. 检查不同类型标签的显示

**预期结果**：
- 成功标签显示为玉色（#5f8d6e）
- 警告标签显示为古铜金（#b8860b）
- 危险标签显示为朱砂红（#c8302c）
- 信息标签显示为墨色（#5a5a5a）

#### 测试用例 2：标签悬停效果
**步骤**：
1. 鼠标悬停在标签上
2. 观察样式变化

**预期结果**：
- 标签向上移动 1px
- 显示阴影效果
- 过渡动画流畅（150ms）

#### 测试用例 3：标签关闭功能
**步骤**：
1. 点击标签关闭按钮
2. 验证标签消失

**预期结果**：
- 关闭按钮悬停时背景变色
- 点击后标签平滑消失
- 无布局跳动
