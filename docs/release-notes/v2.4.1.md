# v2.4.1 更新内容

> 发布日期:2026-10-27
> 上一版本:v2.4.0(修仙导入导出修复、埋点/排行榜迁移阿里云、Evolve 上线)

## 🎉 界面全新改版

- **全部游戏顶部导航统一升级**:毛玻璃质感导航栏,统一的返回按钮、图标磁贴与操作按钮,9 款游戏体验一致
- **退出弹窗重新设计**:"继续游戏"成为醒目主按钮(防误触),支持 Esc 关闭,弹出动画更顺滑
- **首页卡片精简**:标签最多显示 3 个,难度/时长合并为一行,来源仓库地址改为右上角一键复制图标,一屏可见更多游戏
- **俄罗斯方块布局重排**:棋盘随窗口大小自适应放大(最高 1.5 倍)成为视觉重心,分数/等级/行数合并为紧凑面板

## 🔧 优化与修复

- 修复排行榜为空时误显示"等待数据"的问题,现在会提示"虚位以待,打完一局上传分数,第一名就是你"
- 修复小黑屋(A Dark Room)新用户首次进入显示英文的问题
- 修复文字修仙反复进出游戏后年龄增长过快的问题(计时器泄漏)
- 退出游戏时自动保存逻辑增强(糖果盒子2/文字修仙退出前自动云保存)
- 移除打赏入口

## 🛠 技术性变更(开发者向)

- 新增 GameShell 统一游戏壳与设计令牌体系,7 个视图壳层重复代码约 2400 行收敛为一份
- 埋点/排行榜全部运行在自建阿里云服务上(pantry 平台已于 2026-10 停服)
